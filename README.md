# TechSmart Capstone Project

## Project Overview

This analytical project was completed as part of the 'SQL for Data Analysis and Business Insights' course.
 
## Analytical Tasks

1. Identifying opportunities to improve TechSmart’s retail operations in North America and Europe 
2. Developing a robust data-cleaning process and optimizing the performance of an SQLite database 

## Tools

- Python
- Pandas
- SQLite
- MS Office
- GitHub

## Data

A small, educational dataset was used, containing uncleaned information regarding the operations of a retail chain. This dataset includes:
- <b>Employee_Records:</b> Information about employees, their roles, and sales performance
- <b>Product_Details:</b> Details about products, including categories and inventory
- <b>Customer_Demographics:</b> Customer information and loyalty program status
- <b>Sales_Transactions:</b> Transaction data linking customers, products, and employees

## Analysis

The project includes:

- Database creation
- Data cleaning
- Data analysis
- SQL optimization
- Reporting insights
